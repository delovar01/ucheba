# ucheba

Личный сайт для учёбы: уроки по шагам, повторение, сроки и карта пар. Статика без сборки: HTML, CSS и немного JS.

- `index.html` — главная: текущий урок, повторение, карта, блок «Горит».
- `assets/sroki.js` — сроки сдач для блока «Горит».
- `assets/karta.js` — пары с 1.09 по предметам для страницы `karta/`.
- `uroki/` — уроки, `povtorenie/` — вопросы с ответами, `karta/` — карта пар.
- `DESIGN.md` — шрифт, цвета, отступы и компоненты. Новое оформление берёт значения оттуда.
- Урок: `<body data-urok="id">`, шаги — `<section class="shag" data-shag>`, блок после шагов — `id="posle-shagov"`, в конце `.otmetka`. Прогресс и отметка «пройден» хранятся в localStorage под ключом `urok:<id>`.
- `sw.js` — офлайн. После любой правки поднять `VERSIYA` и добавить новые файлы в `STRANICY`.
- Формулы: добавить на страницу `data-formuly` к `<main>` и писать `\( … \)` или `$$ … $$`.

Открыть локально: любой статический сервер из корня папки.
