Модификатор доступа это слово перед полем или методом, которое говорит, кто его видит. private значит «только код внутри этого класса». public значит «все». Ошибка age has private access in Dog: поле закрыто, снаружи его не прочитать и не поменять, это проверяет компилятор.

Внутри класса поле доступно как раньше: метод say спокойно читает name. Правило слайдов: поля класса делаем всегда private, методы, которые нужны снаружи, public.

Шаг 8 из 12

Не каждому полю сеттер

У счёта нет setBalance. Баланс меняют только две операции, и каждая со своей проверкой.

public void deposit(double amount) {
    if (amount <= 0) {
        throw new IllegalArgumentException("Сумма должна быть больше нуля: " + amount);
    }
    balance += amount;
}

public boolean withdraw(double amount) {
    if (amount <= 0 || amount > balance) {
        return false;
    }
    balance -= amount;
    return true;
}

Почему отказы разные, громкий и тихий, как в шагах 5 и 6. Положить ноль или минус может только ошибка в программе, такого быть не должно, поэтому deposit бросает исключение. А снять больше, чем есть, это обычная жизненная ситуация, «не хватает денег»: withdraw тихо отвечает false, и вызывающий код сам решает, что показать человеку.

System.out.println(card.getBalance());

true
950.0

Геттеры и сеттеры не обязаны идти парами. Методы класса повторяют действия из жизни: в банке нельзя «установить баланс», можно положить и снять. Поэтому сеттера нет, а снаружи баланс меняется только через deposit и withdraw.

Шаг 9 из 12

final: неизменяемый объект

Пример со слайдов: имя студента и номер студенческого после создания не меняются.

class Student {
    private final String name;
    private final String cardId;

    public Student(String name, String cardId) {
        this.name = name;
        this.cardId = cardId;
    }

    public String getName() {
        return name;
    }

    public String getCardId() {
        return cardId;
    }
}

final у поля значит «присвоить можно один раз». Значение задают при объявлении или в каждом конструкторе, потом поменять нельзя, это ошибка компиляции. Сеттер для final поля не нужен. Объект, у которого все поля final, неизменяемый: каким создали, таким и останется. По слайдам такие объекты полезны, когда с одним объектом одновременно работают несколько частей программы. Такую программу в курсе пока не пишем.

Шаг 11 из 12

toString: как объект печатается

Класс Cat без ничего лишнего, System.out.println(new Cat("Мурка"));:

Cat@3e3abc88

Имя класса и служебный номер, на каждом запуске свой. Научим собаку печататься по-человечески, в стиле класса SimpleCar Корелина:

class Dog {
    private final String name;
    private final int age;

    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    @Override
    public String toString() {
        return "Dog{name='" + name + "', age=" + age + "}";
    }
}
Dog dog = new Dog("Мухтар", 5);
System.out.println(dog);
System.out.println("Собака: " + dog);
Dog{name='Мухтар', age=5}
Собака: Dog{name='Мухтар', age=5}

У любого объекта Java есть метод toString(), он превращает объект в строку. println и склейка через + вызывают его сами. Свой toString заменяет стандартный. @Override над методом это пометка «я заменяю метод, который уже есть», её проверяет компилятор.

        this.y = y;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) {
            return true;
        }
        if (!(o instanceof Point)) {
            return false;
        }
        Point p = (Point) o;
        return x == p.x && y == p.y;
    }

    @Override
    public int hashCode() {
        return Objects.hash(x, y);
    }
}

Стандартный equals у объекта сравнивает ссылки, как ==. Свой equals сравнивает поля. Схема всегда одна: тот же объект, значит true. Не точка или null, значит false, это проверяет instanceof. Дальше привести o к Point и сравнить поля.

Новые слова по порядку. Object это общий тип для любого объекта Java, в такой параметр можно передать и точку, и строку, и собаку. o instanceof Point отвечает true, если в o лежит точка, и false для null. (Point) o говорит компилятору «считай o точкой», только после этого у неё можно взять p.x. Поле p.x закрыто, но код внутри класса Point видит закрытые поля любой точки, не только своей.

Параметр именно Object, а не Point, иначе это не замена, и @Override не соберётся.

Вместе с equals всегда заменяют hashCode по тем же полям. Этот метод сворачивает поля в одно число, а Objects.hash(x, y) считает его за тебя. Обычному ArrayList хватает equals.

hashCode нужен быстрым коллекциям. HashSet это набор без повторов, HashMap таблица «ключ → значение», как словарь. Подробно они будут в уроке про исключения, а сейчас достаточно знать одно: они ищут объект сначала по этому числу, и без своего hashCode две равные точки для них окажутся разными.
