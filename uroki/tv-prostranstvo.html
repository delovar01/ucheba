Вероятностное пространство и алгебра событий

Теорвер · лекция 5.10 и практика 6.10 · около 60 минут

Лист Сергеева 5.10: теория, тест на 5 вопросов, 17 задач практики и самостоятельная. Первая половина урока про то, как записывать события через буквы \(A, B, C\), это вся практика 6.10. Вторая половина про то, что такое вероятность: тройка \((\Omega, \mathcal F, P)\) и три аксиомы, на которых держится весь курс. Аксиомы взяты из учебника Сергеева, параграф 3.1.

Нужны события как множества и σ-алгебра. Как проходить: читаешь шаг, переписываешь рамку, решаешь «сделай сам» на бумаге и только потом открываешь ответ.

Шаг 1 из 9

Слова с листа: исход, выборочное пространство, синглетон

Исход \(\omega\) это результат случайного эксперимента. Выборочное пространство \(\Omega\), по-английски sample space, это множество всех возможных исходов, оно непустое. Синглетон, или элементарное событие, это событие из одного исхода \(\{\omega\}\).

Событие теперь определяют строже: его требуют взять из σ-алгебры на \(\Omega\). Эту σ-алгебру обозначают рукописной буквой \(\mathcal F\), читается «эф». Исходы, из которых событие состоит, называют благоприятными для него. Кубик, \(\omega_2\) значит «выпало 2»: событие «чётное» \(= \{\omega_2, \omega_4, \omega_6\}\), благоприятных исходов три.

Исход это точка \(\omega\), событие это множество точек. Синглетон \(\{\omega\}\) уже событие, а не исход. Событие называют случайным, если оно не невозможное и не достоверное.

Сделай сам. Две монеты, у каждой стороны 0 и 1. Запиши \(\Omega\) и благоприятные исходы события «хотя бы одна единица». Вопрос 4 теста: что из этого полная группа при одном броске монеты, \(\{0; 1\}\) или \(\{\{0\}; \{1\}\}\)?
Показать ответСкрыть ответ

\(\Omega = \{00, 01, 10, 11\}\). Благоприятные для «хотя бы одна единица»: 01, 10, 11. Полная группа \(\{\{0\}; \{1\}\}\): она состоит из событий.

Выбрать \(\{0; 1\}\). Это сами исходы, то есть \(\Omega\), а полная группа это набор событий, каждое из которых множество.

Исход ω, выборочное пространство Ω (все исходы), синглетон {ω}.

Событие: элемент σ-алгебры F. Благоприятные исходы: те, из которых оно состоит.

Шаг 2 из 9

События через A₁, A₂, A₃: стрелок

Задача 1 практики. Стрелок стреляет три раза, \(A_i\) значит «попал при \(i\)-м выстреле». Исход это тройка из 0 и 1, где 1 попадание. Исходов \(2^3 = 8\): 000, 001, …, 111.

«Хотя бы одно попадание» это сумма: \(A = A_1 + A_2 + A_3\), семь исходов, все кроме 000. «Три попадания» это произведение: \(B = A_1 A_2 A_3\), только 111. «Три промаха»: \(C = \bar A_1 \bar A_2 \bar A_3\), только 000.

«Хотя бы одно» записывают суммой, «все» произведением, «не произошло» чертой над буквой.

Два события противоположны, если одно из них значит «другое не произошло», как \(A\) и \(\bar A\). Здесь \(C\) противоположно \(A\): по де Моргану \(\bar A_1 \bar A_2 \bar A_3 = -(A_1 + A_2 + A_3)\).

Сделай сам. Вырази через \(A_i\) и выпиши исходы: \(D\) хотя бы один промах, \(E\) не меньше двух попаданий. Какие события из этой задачи противоположны друг другу?
Показать ответСкрыть ответ

\(D = \bar A_1 + \bar A_2 + \bar A_3 = \bar B\), семь исходов, все кроме 111. \(E = A_1A_2 + A_1A_3 + A_2A_3\), исходы 011, 101, 110, 111. Это та же формула, что у комитета из трёх.

Противоположны \(A\) и \(C\), \(B\) и \(D\), а ещё \(E\) и «не больше одного попадания» \(\{000, 001, 010, 100\}\).

Записать «хотя бы один промах» как \(\bar A_1 \bar A_2 \bar A_3\). Это три промаха из трёх. «Хотя бы один» всегда сумма.

Хотя бы одно: A₁ + A₂ + A₃. Все: A₁A₂A₃. Ни одного: Ā₁Ā₂Ā₃.

Хотя бы один промах = −(все попадания).

Шаг 3 из 9

Словарь: «ровно», «хотя бы», «не больше»

Задача 5 практики, девять событий через \(A, B, C\). Каждое «произошло» пишется буквой, каждое «не произошло» буквой с чертой.

словамиформула
только A\(A\bar B\bar C\)
A и B, но не C\(AB\bar C\)
хотя бы одно\(A + B + C\)
хотя бы два\(AB + AC + BC\)
ровно одно\(A\bar B\bar C + \bar A B\bar C + \bar A\bar B C\)
ни одного\(\bar A\bar B\bar C = -(A + B + C)\)
не больше двух\(-(ABC) = \bar A + \bar B + \bar C\)

«Ровно» раскладывают на несовместные куски, по одному на каждый вариант, и соединяют плюсом. В каждом куске стоят все три буквы.

Сделай сам. Запиши «произошло ровно два из трёх». Задача 4: три монеты, \(A, B, C\) «на первой, второй, третьей выпала 1». Запиши «на первой 0 и хотя бы на одной из остальных 1».
Показать ответСкрыть ответ

Ровно два: \(AB\bar C + A\bar B C + \bar A BC\). Монеты: \(\bar A(B + C)\).

Записать «ровно два» как \(AB + AC + BC\). Это «хотя бы два», сюда входит и 111, где выпали все три. Чтобы вышло «ровно», третью букву пишут с чертой.

Ровно одно: AB̄C̄ + ĀBC̄ + ĀB̄C. Ровно два: ABC̄ + AB̄C + ĀBC.

Хотя бы два: AB + AC + BC. Не больше двух: Ā + B̄ + C̄.

Шаг 4 из 9

Цепи из элементов: де Морган в железе

Задача 10 практики. В цепи три элемента, \(A_i\) значит «элемент \(i\) вышел из строя», \(B\) значит «цепь не проводит ток».

Последовательная цепь рвётся, если сломан хоть один элемент: \(B_1 = A_1 + A_2 + A_3\). Работает она, только если целы все: \(\bar B_1 = \bar A_1 \bar A_2 \bar A_3\).

Переход от \(B_1\) к \(\bar B_1\) это закон де Моргана: сумма превращается в произведение, и черта переходит на каждую букву.

Сделай сам. Те же три элемента соединены параллельно. Вырази \(B_2\) «цепь не проводит ток» и \(\bar B_2\) «цепь работает».
Показать ответСкрыть ответ

Параллельная цепь рвётся, только если сломаны все: \(B_2 = A_1 A_2 A_3\). Работает, если цел хоть один: \(\bar B_2 = \bar A_1 + \bar A_2 + \bar A_3\).

Перепутать, что значит буква. В контактных схемах буква была «контакт замкнут», а здесь \(A_i\) значит «элемент сломан». Поэтому последовательной цепи здесь соответствует сумма, а не произведение.

Aᵢ = элемент сломан. Последовательно: не работает A₁ + A₂ + A₃. Параллельно: не работает A₁A₂A₃.

Шаг 5 из 9

Полная группа и разбиение

Полная группа в \((\Omega, \mathcal F)\) это набор событий из \(\mathcal F\): каждое непустое, попарно не пересекаются, в сумме \(\Omega\). Разбиение \(\Omega\) это то же самое, только куски можно брать из всех подмножеств \(\Omega\). Если \(\mathcal F\) булеан, разницы нет.

Задача 3: кубик бросают дважды, \(\Omega\) это 36 упорядоченных пар \((i, j)\). Полная группа, например: \(H_1\) «сумма очков чётная» и \(H_2\) «сумма нечётная», по 18 исходов.

В полной группе нет пустого события, куски не пересекаются и вместе дают \(\Omega\).

Сделай сам. Вопрос 5 теста, варианты пересказаны по смыслу. Что из этого полная группа при броске двух монет? (1) \(\{00, 01, 10, 11\}\). (2) \(\{\{00, 01\}, \{01, 10, 11\}, \varnothing\}\). (3) \(\{\{00\}, \{01\}, \{10\}, \{11\}\}\). (4) \(\{\{00, 11\}, \{01, 10\}, \varnothing\}\).
Показать ответСкрыть ответ

Вариант (3). В (1) исходы, а не события. В (2) куски пересекаются по 01, и есть пустое. В (4) куски хорошие, но лишнее \(\varnothing\).

Выбрать (4): «пустое ничего не портит». По определению на листе каждое событие полной группы непустое.

Полная группа: события из F, непустые, попарно не пересекаются, сумма Ω.

Шаг 6 из 9

Вероятность и три аксиомы

Каждый кусок уже был. \(\Omega\) это исходы. \(\mathcal F\) это σ-алгебра, список событий, про которые можно спрашивать. Новое только \(P\): функция, которая каждому событию из \(\mathcal F\) ставит число.

От неё требуют три вещи, это аксиомы Колмогорова.

1. Неотрицательность: \(P(A) \geqslant 0\) для любого \(A \in \mathcal F\).
2. Нормировка: \(P(\Omega) = 1\).
3. σ-аддитивность: если \(A_1, A_2, \ldots\) попарно несовместны, то \(P(A_1 + A_2 + \ldots) = P(A_1) + P(A_2) + \ldots\)

Вероятностное пространство это тройка \((\Omega, \mathcal F, P)\): исходы, σ-алгебра событий и вероятность на ней, подчинённая трём аксиомам.

Пример с лекции, монетка. \(\Omega = \{T, H\}\), T решка, H орёл, \(\mathcal F\) булеан из четырёх событий. Если монета честная, \(P(\{T\}) = P(\{H\})\). События несовместны и в сумме \(\Omega\), по аксиомам 3 и 2 их сумма равна 1. Значит, каждая вероятность \(\frac12\).

Сделай сам. Выведи из аксиом, что \(P(\varnothing) = 0\). Подсказка: аксиома 3 про бесконечный ряд, поэтому возьми ряд \(\Omega, \varnothing, \varnothing, \ldots\). Эти события попарно несовместны, а их сумма равна \(\Omega\).
Показать ответСкрыть ответ

По аксиоме 3: \(P(\Omega + \varnothing + \varnothing + \ldots) = P(\Omega) + P(\varnothing) + P(\varnothing) + \ldots\) Слева \(P(\Omega) = 1\). Получаем \(1 = 1 + P(\varnothing) + P(\varnothing) + \ldots\) Вычтем 1 из обеих частей: \(0 = P(\varnothing) + P(\varnothing) + \ldots\), то есть сумма бесконечного числа одинаковых слагаемых \(P(\varnothing) \geqslant 0\) равна нулю. Так бывает, только если \(P(\varnothing) = 0\): будь \(P(\varnothing)\) хоть 0.001, уже тысяча слагаемых дала бы 1, а не 0.

Отсюда же следует, что аксиома 3 работает и для двух, трёх, любого конечного числа несовместных событий: допиши к ним в ряд пустые множества, каждое добавит 0. Этим и пользуются в монетке выше и в следующих шагах.

Написать «\(P(\varnothing) = 0\), потому что невозможное». Это верно по смыслу, но в аксиомах такого пункта нет. Вывод из аксиом и есть доказательство.

(Ω, F, P). Аксиомы: P(A) ≥ 0, P(Ω) = 1, для попарно несовместных P(A₁ + A₂ + …) = P(A₁) + P(A₂) + …

Шаг 7 из 9

Вероятность противоположного события

Событие \(A\) и его дополнение \(-A\) несовместны и вместе дают \(\Omega\). По аксиомам 3 и 2: \(P(A) + P(-A) = 1\).

\(P(-A) = 1 - P(A)\). Вместе с де Морганом это главный приём курса: \(P(\text{хотя бы одно}) = 1 - P(\text{ни одного})\).

Зачем приём нужен. «Хотя бы одно попадание из трёх» состоит из семи исходов, а «ни одного» из одного. Посчитать один исход и вычесть из единицы проще, чем сложить семь.

Сделай сам. Вероятность, что стрелок промахнётся всеми тремя выстрелами, 0.027. Какова вероятность хотя бы одного попадания? А если вероятность трёх попаданий 0.343, какова вероятность хотя бы одного промаха?
Показать ответСкрыть ответ

Хотя бы одно попадание противоположно трём промахам: \(1 - 0.027 = 0.973\). Хотя бы один промах противоположен трём попаданиям: \(1 - 0.343 = 0.657\).

Считать, что «хотя бы одно попадание» противоположно «хотя бы одному промаху». Они прекрасно случаются вместе, например 101. Противоположное к «хотя бы одно» это «ни одного».

P(−A) = 1 − P(A). P(хотя бы одно) = 1 − P(ни одного). P(∅) = 0.

Шаг 8 из 9

Равновозможные исходы: вероятность как доля

Монетку из шага 6 можно обобщить. Пусть \(\Omega\) из \(n\) исходов, и все они равновозможны, как грани честного кубика. Синглетоны несовместны и в сумме дают \(\Omega\), поэтому их \(n\) одинаковых вероятностей в сумме 1. Каждая равна \(\frac1n\).

Событие из \(k\) благоприятных исходов это сумма \(k\) несовместных синглетонов. По аксиоме 3 его вероятность \(k \cdot \frac1n\).

Если \(n\) исходов равновозможны, то \(P(A) = \dfrac{k}{n}\), где \(k\) число благоприятных для \(A\) исходов.

Кубик: \(P(\text{чётное}) = \frac36 = \frac12\).

Сделай сам. Две честные кости, 36 равновозможных пар. Какова вероятность, что сумма очков равна 7? Выпиши благоприятные пары.
Показать ответСкрыть ответ

(1, 6), (2, 5), (3, 4), (4, 3), (5, 2), (6, 1), шесть пар. \(P = \frac{6}{36} = \frac16\).

Считать (3, 4) и (4, 3) одним исходом и получить 3 пары. Кости разные, первая и вторая, поэтому пары упорядоченные, иначе исходы не будут равновозможными.

n равновозможных исходов: P(A) = k / n, k = число благоприятных.

Шаг 9 из 9

Вероятность суммы любых двух событий

Аксиома 3 складывает только несовместные события. А если \(A\) и \(B\) пересекаются? Режем, как в уроке про множества: \(A + B = A + (B - A)\), и куски несовместны. А \(B = (B - A) + AB\), отсюда \(P(B - A) = P(B) - P(AB)\).

Собираем: \(P(A + B) = P(A) + P(B - A)\) по аксиоме 3, а вместо \(P(B - A)\) подставляем \(P(B) - P(AB)\).

\(P(A + B) = P(A) + P(B) - P(AB)\). Пересечение вычитают, потому что в \(P(A) + P(B)\) оно посчитано дважды.

Кубик, \(A\) «чётное», \(B\) «больше трёх»: \(\frac36 + \frac36 - \frac26 = \frac46\). Проверка: \(A + B = \{2, 4, 5, 6\}\), четыре исхода из шести.

Эта формула записана на листе 12.10 вместе с версией для трёх событий: \(P(A + B + C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)\). Её называют формулой включений и исключений.

Сделай сам. \(P(A) = 0.5\), \(P(B) = 0.4\), \(P(AB) = 0.2\). Найди \(P(A + B)\) и вероятность, что не случилось ни одно из двух.
Показать ответСкрыть ответ

\(P(A + B) = 0.5 + 0.4 - 0.2 = 0.7\). Ни одного: \(1 - 0.7 = 0.3\).

Сложить без вычитания и получить 0.9. Сложение работает только для несовместных, а здесь \(P(AB) = 0.2\), не ноль.

P(A + B) = P(A) + P(B) − P(AB). Для несовместных P(AB) = 0.

Три события: + одиночные, − пары, + тройка.
