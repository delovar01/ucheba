Любая программа на Java живёт внутри такого каркаса. Пока его не разбираем по словам, просто переписываем каждый раз одинаково.

Функция y = √(x − 3). Корень из отрицательного числа не берётся, поэтому при x < 3 функция не определена. Множество x, где функцию можно посчитать, называется областью определения.

if (условие) { А } else { Б } выполняет А, если условие верно, и Б, если нет. Выполняется ровно одна из двух веток.

Сравнения: <, >, <=, >=, == равно, != не равно. Равенство пишется двумя знаками.

Шаг 8 из 12

Два условия сразу: || и &&

Функция y = √(x + 2) / (x − 3). Здесь два запрета: под корнем не меньше нуля, то есть x ≥ −2, и знаменатель не ноль, то есть x ≠ 3. Функция не определена, если нарушен хотя бы один.

double x = 7;
if (x < -2 || x == 3) {
    System.out.println("Функция не определена");
} else {
    double y = Math.sqrt(x + 2) / (x - 3);
    System.out.println("y = " + y);
}

Напечатается y = 0.75: корень из 9 это 3, делим на 4.

|| значит «или»: условие верно, если верна хотя бы одна часть. && значит «и»: обе части сразу. ! переворачивает условие: !(x > 0) верно, когда x не больше нуля.

Сделай сам. Функция y = √(5 − x) / x. Запиши условие «не определена» и посчитай y при x = 1.
Показать ответСкрыть ответ

    System.out.println("Функция не определена");
} else {
    double y = Math.sqrt(5 - x) / x;
    System.out.println("y = " + y);
}

Под корнем 5 − x ≥ 0, значит x ≤ 5, нарушение это x > 5. Знаменатель x, нарушение x == 0. При x = 1 напечатается y = 2.0.

Соединить запреты через &&. Число не может быть одновременно больше 5 и равно 0, условие никогда не сработает. При x = 0 программа посчитает и напечатает y = Infinity, бесконечность, вместо сообщения.

Запреты области определения соединяются ||: нарушен хотя бы один.

&& это «и», || «или», ! «не».

Шаг 12 из 12

Ввели не число: hasNextDouble

Шаг 11 ловит число вне границ. А если пользователь вместо числа напечатал abc, nextDouble() падает сам, и твоё сообщение не появится. Поэтому сначала спрашиваем, число ли там.

import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);
        // 1. что делает программа
        System.out.println("Программа считает цену со скидкой.");
        // 2. просим данные и 3. проверяем
        System.out.println("Цена, руб:");
        if (!sc.hasNextDouble()) {
            System.out.println("Ошибка: цена должна быть числом");
            return;
        }
        double price = sc.nextDouble();
        if (price <= 0) {
            System.out.println("Ошибка: цена больше нуля");
            return;
        }
        System.out.println("Скидка, %:");
        if (!sc.hasNextDouble()) {
            System.out.println("Ошибка: скидка должна быть числом");
            return;
        }
        double discount = sc.nextDouble();
        if (discount < 0 || discount > 100) {
            System.out.println("Ошибка: скидка от 0 до 100");
            return;
        }
        // 4. считаем
        double total = price * (100 - discount) / 100;
        // 5. выводим
        System.out.println("К оплате: " + total + " руб");
    }
}
