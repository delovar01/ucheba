Шаг 4 из 10

Конструктор: объект сразу с данными

class Dog {
    String name;
    int age;

    Dog(String n, int a) {
        name = n;
        age = a;
    }

    void say() {
        System.out.println(name + ", возраст " + age + ": ГАВ!");
    }
}

Строки внутри main:

Dog a = new Dog("Мухтар", 5);
Dog b = new Dog("Рекс", 2);
a.say();
b.say();
Мухтар, возраст 5: ГАВ!
Рекс, возраст 2: ГАВ!

Конструктор это особый метод, который заполняет объект при создании. Имя совпадает с именем класса, типа возврата нет, даже void. Вызывается он сам, через new: значения в скобках new Dog("Мухтар", 5) попадают в параметры конструктора.

По слайдам: если в классе нет ни одного конструктора, Java сама добавляет пустой, конструктор по умолчанию. Поэтому в шагах 1–3 работал new Dog(). Конструкторов можно написать несколько, с разными параметрами.

Шаг 9 из 10

Части списком: ArrayList

У Корелина Computer хранит не по полю на деталь, а список: деталей может быть сколько угодно, две планки памяти тоже.

import java.util.ArrayList;

class Part {
    String name;
    double price;

    Part(String name, double price) {
        this.name = name;
        this.price = price;
    }
}

class Computer {
    ArrayList<Part> parts = new ArrayList<>();

    void add(Part p) {
        parts.add(p);
    }

    double totalPrice() {
        double sum = 0;
        for (Part p : parts) {
            sum += p.price;
        }
        return sum;
    }
}

Строки внутри main, детали и цены из примера лектора:

ArrayList<Part> это список объектов Part, который растёт сам, в отличие от массива. add кладёт в конец, size() возвращает число элементов. Цикл for (Part p : parts) читается «для каждой детали p из списка»: он проходит все элементы по очереди без индексов.

Цикл «для каждого» делает то же, что знакомый цикл по номерам, только короче. Взять элемент по номеру можно через parts.get(i):

for (int i = 0; i < parts.size(); i++) {
    Part p = parts.get(i);
    sum += p.price;
}

Тип в угловых скобках обязателен, а справа хватает пустых <>. Нужен import java.util.ArrayList;.

Шаг 10 из 10

Модель банка: клиенты, счета, перевод

Задача с лекции, seminar1-todo-bank: банк заводит счета клиентам и переводит деньги между ними. Сначала решить, какие классы нужны: счёт знает номер и баланс, клиент имеет список счетов, банк проводит перевод.

import java.util.ArrayList;

class Account {
    String number;
    double balance;

    Account(String number, double balance) {
        this.number = number;
        this.balance = balance;
    }

    void deposit(double amount) {
        balance += amount;
    }

    boolean withdraw(double amount) {
        if (amount > balance) {
            return false;
        }
        balance -= amount;
        return true;
    }
}

class Client {
    String name;
    ArrayList<Account> accounts = new ArrayList<>();

    Client(String name) {
        this.name = name;
    }

    void addAccount(Account a) {
        accounts.add(a);
    }

    double total() {
        double sum = 0;
        for (Account a : accounts) {
            sum += a.balance;
        }
        return sum;
    }
}

class Bank {
    static boolean transfer(Account from, Account to, double amount) {
        if (!from.withdraw(amount)) {
            return false;
        }
        to.deposit(amount);
        return true;
    }
}
