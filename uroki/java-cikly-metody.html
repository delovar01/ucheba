Шаг 1 из 11

for: повторить заданное число раз

Хотим квадраты чисел от 1 до 5. Писать пять одинаковых строк не надо.

for (int i = 1; i <= 5; i++) {
    System.out.println(i + " в квадрате = " + i * i);
}
1 в квадрате = 1
2 в квадрате = 4
3 в квадрате = 9
4 в квадрате = 16
5 в квадрате = 25

for (начало; условие; шаг) { тело } повторяет тело, пока условие верно. Порядок: один раз выполняется начало int i = 1. Дальше по кругу: проверка i <= 5, тело, шаг i++. Условие стало ложным, цикл кончился.

i++ значит «прибавить к i единицу». Переменная i называется счётчиком, она живёт только внутри цикла. Один проход тела называют итерацией.

Сделай сам. Выведи числа от 10 до 0 через два: 10, 8, 6… Подсказка: i -= 2 значит «уменьшить i на 2».
Показать ответСкрыть ответ 
for (int i = 10; i >= 0; i -= 2) {
    System.out.println(i);
}

Напечатает 10, 8, 6, 4, 2, 0, каждое на своей строке.

Оставить условие i <= 0 по привычке. При i = 10 оно сразу ложно, и тело не выполнится ни разу. Программа ничего не напечатает и не скажет об ошибке.

for (int i = 1; i <= n; i++) повторяет тело n раз.

Условие проверяется перед каждым проходом. Ложно сразу, тело не выполнится.

do-while: хотя бы один раз

Просим число от 1 до 10 и спрашиваем снова, пока не введут подходящее. Спросить нужно точно хотя бы раз.

Scanner sc = new Scanner(System.in);
int n;
do {
    System.out.println("Число от 1 до 10:");
    n = sc.nextInt();
} while (n < 1 || n > 10);
System.out.println("Принято: " + n);

Ввели 15, потом 0, потом 7:

Число от 1 до 10:
Число от 1 до 10:
Число от 1 до 10:
Принято: 7

do { тело } while (условие); сначала выполняет тело, потом проверяет условие. Значит, тело выполнится хотя бы один раз. У while условие проверяется до тела.

int n; объявлена до цикла без значения: переменная, заведённая внутри фигурных скобок do, в условии после while уже не видна. Цифры числа 0 из шага 3 честно считаются через do-while: одна цифра.

    k++;
} while (k < 3);
System.out.println(k);
Показать ответСкрыть ответ

6. Тело выполнилось один раз, k стало 6, потом проверка 6 < 3 ложна, выход. У обычного while с тем же условием тело не выполнилось бы, осталось бы 5.

Забыть ; после while (k < 3). У do-while она обязательна, без неё программа не соберётся: ';' expected.

Шаг 7 из 11

Статический метод: свой кусок кода с ответом

Это задание 4 ПР2. Метод это кусок кода с именем, который можно вызвать сколько угодно раз и передать ему числа. Как Math.sqrt, только свой. Здесь целая программа: метод пишется рядом с main, внутри класса.

public class Main {
    public static void main(String[] args) {
        double s1 = area(3, 4);
        double s2 = area(2.5, 2);
        System.out.println(s1);
        System.out.println(s2);
    }

    static double area(double a, double b) {
        return a * b;
    }
}
12.0
5.0

static тип имя(параметры) { … return значение; }. Тип перед именем говорит, что метод вернёт. Параметры это переменные, в которые при вызове попадут числа из скобок. return отдаёт ответ туда, откуда метод позвали, и заканчивает метод.

При вызове area(3, 4) в a попадает 3, в b попадает 4, метод возвращает 12.0, и это число кладётся в s1. Слово static пока просто пиши всегда, его смысл будет в теме про классы.

Сделай сам. Напиши метод cube, который возвращает куб целого числа. Что напечатает System.out.println(cube(3) + cube(2));?
Показать ответСкрыть ответ 
static int cube(int n) {
    return n * n * n;
}

Напечатает 35: 27 + 8.

Посчитать и забыть return: int c = n * n * n; и всё. Метод обещал вернуть int, но не вернул, программа не соберётся: missing return statement.

static double имя(double a, double b) { return …; } рядом с main.

Вызов имя(3, 4) подставляет числа в параметры по порядку.

Шаг 10 из 11

Метод ввода: спрашивать, пока не введут нормальное

В первом уроке программа при плохом вводе останавливалась. С циклом можно спросить ещё раз. Соберём это в метод, чтобы не повторять для каждого числа.

import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);
        double price = readInRange(sc, "Цена, руб:", 1, 1000000);
        System.out.println("Цена: " + price);
    }

    static double readInRange(Scanner sc, String prompt, double min, double max) {
        while (true) {
            System.out.println(prompt);
            if (!sc.hasNextDouble()) {
                System.out.println("Это не число, ещё раз");
                sc.next();
            } else {
                double x = sc.nextDouble();
                if (x >= min && x <= max) {
                    return x;
                }
                System.out.println("Число вне границ, ещё раз");
            }
        }
    }
}

Ввели abc, потом -5, потом 1500:

Цена, руб:
Это не число, ещё раз
Цена, руб:
Число вне границ, ещё раз
Цена, руб:
Цена: 1500.0

while (true) крутится без конца, а выходом служит return x;: он отдаёт хорошее число и сразу заканчивает и цикл, и метод.

Scanner передаём в метод параметром, так метод читает тот же ввод, что и main. Строка-подсказка prompt и границы тоже параметры, поэтому один метод годится и для цены, и для скидки. sc.next() забирает из ввода плохое слово abc и выбрасывает его.

Развить программу ПР1 циклом и методами

Задание 5 ПР2 разрешает строить решение на программе из прошлой практической. Покажем на программе скидки из первого урока, свою из задания 4 ПР1 развиваешь так же. Метод readInRange из шага 10 вставь в класс без изменений.

import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in).useLocale(Locale.US);
        System.out.println("Программа считает цену со скидкой.");
        double more;
        do {
            double price = readInRange(sc, "Цена, руб:", 1, 1000000);
            double discount = readInRange(sc, "Скидка, %:", 0, 100);
            System.out.println("К оплате: " + discounted(price, discount) + " руб");

    static double discounted(double price, double discount) {
        return price * (100 - discount) / 100;

}
