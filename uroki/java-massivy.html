Заполнить массив по формуле

Квадраты чисел от 0 до 5. Значения заранее не пишем, считаем в цикле. Строки внутри main, import java.util.Arrays; сверху, как в шаге 2.

int[] sq = new int[6];

Условие i < sq.length именно со знаком «меньше»: последний индекс 5, а длина 6.

Сумма и среднее массива

Тот же массив 7, 2, 9, 4. Это накопитель из урока про циклы, только складываем ячейки.

int[] a = {7, 2, 9, 4};
int sum = 0;
for (int i = 0; i < a.length; i++) {
    sum += a[i];
}
double avg = (double) sum / a.length;
System.out.println("Сумма: " + sum);
System.out.println("Среднее: " + avg);
Сумма: 22
Среднее: 5.5

Обход массива: for (int i = 0; i < a.length; i++) и внутри работа с a[i]. Так проходят по массиву для любого подсчёта: сумма, количество, произведение, только чётные, только положительные.

Среднее это сумма, делённая на число элементов. Сумма целая, длина целая, поэтому (double) перед делением, как в первом уроке.

int[] a = {3, 5, 4, 6, 6, 8};

Шаг 8 из 11

Участки: флаг «я сейчас внутри»

Шаг 7 считал пары. А участок это несколько пар подряд, и его надо посчитать один раз. Пример на соседней задаче: сколько участков, где числа растут.

int[] a = {1, 3, 2, 4, 5, 5, 1};
int runs = 0;
boolean inRun = false;
for (int i = 1; i < a.length; i++) {
    if (a[i] > a[i - 1]) {
        if (!inRun) {
            runs++;
            inRun = true;
        }
    } else {
        inRun = false;
    }
}
System.out.println("Участков роста: " + runs);
Участков роста: 2

Ход: 1 и 3 рост, участок начался, runs = 1. 3 и 2 нет, участок кончился. 2 и 4 рост, новый участок, runs = 2. 4 и 5 рост, но мы уже внутри, не считаем. Пары 5 и 5, 5 и 1 не рост. Итого 2: участки 1, 3 и 2, 4, 5.

Флаг это переменная boolean, которая помнит состояние. inRun отвечает на вопрос «сейчас идёт участок?». Участок считаем в момент, когда он начался: пара подходит, а флаг ещё false. Пара не подходит, флаг сбрасываем.

Делать runs++ на каждой подходящей паре, без флага. Это снова подсчёт пар из шага 7, а не участков. На массиве из примера выйдет 3 вместо 2: 4, 5 посчитается как отдельный участок.

Участок считается один раз, в начале: подходит и !inRun.

Не подходит: inRun = false.

Шаг 9 из 11

Участки убывания по правилу Павлова

Одна из задач курса: найти количество участков, на которых элементы монотонно убывают. Монотонно значит без скачков вверх внутри участка. Павлов 10.10 в чате практик пояснил, как считать:

  • Участок это два и больше элемента подряд.
  • Убывание нестрогое: пара подходит, если a[i] <= a[i - 1]. Равные соседи участок не рвут.
  • Участок кончается, когда текущий элемент больше предыдущего.

Его пример: {5, 4, 5, 7, 6, 8, 9, 9, 6, 2}. Участки 5, 4, потом 7, 6, потом 9, 9, 6, 2. Ответ 3.

Правило Павлова это флаг из шага 8, где вместо «рост» стоит «текущий не больше предыдущего». Равенство тоже подходит, поэтому пара 9 и 9 начинает участок.

Проверь любое решение на краях, по правилу ответы такие. Массив из одного элемента: 0, пар нет. Весь массив убывает, например 9, 7, 3: 1. Все равные, например 2, 2, 2: 1.

Три: 8, 6, 6, потом 9, 3, потом 4, 4. Пара 6 и 9 рвёт первый участок, 3 и 4 рвёт второй, а 4 и 4 равные, по правилу это уже убывание.

Программа с флагом и условием a[i] <= a[i - 1] на этих массивах даёт ровно 3, 0, 1, 1 и 3, проверено запуском.

Взять строгое a[i] < a[i - 1]. Тогда 4, 4 не участок, и выйдет 2 вместо 3. Массив 2, 2, 2 даст 0 вместо 1. А на примере Павлова строгое и нестрогое случайно совпадают, оба 3, поэтому проверять только на нём мало.

Шаг 10 из 11

Массив в метод: каждая задача отдельно

В ПР3 несколько задач на один массив. Удобно каждую сделать методом, который принимает массив и возвращает ответ.

public class Main {
    public static void main(String[] args) {
        int[] a = {7, 2, 9, 4};
        int[] empty = {};
        System.out.println(average(a));
        System.out.println(average(empty));
    }

    static double average(int[] a) {
        if (a.length == 0) {
            return 0;
        }
        int sum = 0;
        for (int i = 0; i < a.length; i++) {
            sum += a[i];
        }
        return (double) sum / a.length;
    }
}
5.5
0.0

Параметр метода может быть массивом: int[] a. Метод видит тот же массив, что и main, и работает с ним как обычно. Внутри метода сначала проверяем край, пустой массив, и только потом считаем.

{} это массив без элементов, его длина 0. Без проверки average(empty) поделит 0 на 0 и вернёт NaN, «не число», проверено.

С числом метод работал с копией, урок про методы, шаг 9. С массивом иначе: метод получает тот же самый массив. Если метод что-то запишет в ячейку, это изменение увидит и main.

Сделай сам. Метод static int max(int[] a) возвращает наибольший элемент. Что вернёт для {3, 11, 6}?
Показать ответСкрыть ответ 
static int max(int[] a) {
    int best = a[0];
    for (int i = 1; i < a.length; i++) {
        if (a[i] > best) {
            best = a[i];
        }
    }
    return best;
}

Вернёт 11.

Поставить return best; внутрь цикла. Метод вернёт ответ после первого же сравнения. На {3, 11, 6} это случайно 11, а на {3, 6, 11} метод вернёт 6, проверено. return с итогом стоит после цикла.

static тип имя(int[] a) { …; return ответ; }, ответ после цикла.

Пустой массив проверь в начале метода.
