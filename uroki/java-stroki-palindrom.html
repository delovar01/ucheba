Строки, Scanner и палиндром

Java · лаба 15.09, конспект 05, слайды «Символьный тип. Строки» · к ПР2 и ПР3, срок 1.11 в 00:00 · около 55 минут

На лабе 15.09 Павлов показывал ввод строки через Scanner и проверку палиндрома двумя указателями. Палиндром это слово, которое читается одинаково слева направо и справа налево: шалаш, радар. Десять шагов: длина строки, символ по номеру, обход, два способа читать строку с клавиатуры, сравнение строк, регистр, сам палиндром и его проверка разворотом.

Нужны уроки типы и if и циклы и методы: здесь работают for, while и методы. Новые слова break, -- и ? : объяснены в шагах, где появляются. Где написано «строки внутри main», каркас как в первом уроке.

Переменная типа String хранит не сам текст, а ссылку, адрес объекта в памяти. == сравнивает адреса: это один и тот же объект? Строка со Scanner это новый объект, адрес у неё свой, и == даёт false, хотя буквы те же. a.equals(b) сравнивает буквы. Строки сравнивают только так.

Шаг 8 из 10

Палиндром двумя указателями

Задача с лабы: ввести слово, ответить YES, если оно палиндром, иначе NO.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String word = sc.nextLine();

        int left = 0;
        int right = word.length() - 1;
        boolean isPalindrome = true;

        while (left < right) {
            if (word.charAt(left) != word.charAt(right)) {
                isPalindrome = false;
                break;
            }
            left++;
            right--;
        }
        System.out.println(isPalindrome ? "YES" : "NO");
    }
}

Ввели шалаш, программа напечатала YES. Ввели мопс, NO.

Два указателя это две переменные-номера. left идёт с начала, right с конца, навстречу друг другу. На каждом шаге сравниваем символы под ними. Не равны, значит не палиндром, выходим через break. Равны, сдвигаем оба к середине. Встретились, проверять больше нечего, все пары совпали.

Три новые записи в коде. right-- отнимает от right единицу, как ++ прибавляет. break сразу выходит из цикла. isPalindrome ? "YES" : "NO" выбирает одно из двух значений: если слева от ? true, берётся то, что до двоеточия, иначе то, что после. Это короткий if внутри скобок println.

Ход на «шалаш»: позиции 0 и 4, ш и ш, равны. Позиции 1 и 3, а и а, равны. Теперь left = right = 2, условие left < right ложно, цикл кончился, YES. На «мопс» первая же пара м и с разная, NO после одного сравнения.

Шаг 9 из 10

Палиндром-фраза: пропускать пробелы и знаки

«А роза упала на лапу Азора» тоже палиндром, если не смотреть на пробелы и регистр. Новую «чистую» строку не строим, лишнее перескакиваем указателями. Строки внутри main, s прочитана через nextLine:

int left = 0;
int right = s.length() - 1;
boolean ok = true;
while (left < right) {
    char l = s.charAt(left);
    char r = s.charAt(right);
    if (!Character.isLetterOrDigit(l)) {
        left++;
    } else if (!Character.isLetterOrDigit(r)) {
        right--;
    } else if (Character.toLowerCase(l) != Character.toLowerCase(r)) {
        ok = false;
        break;
    } else {
        left++;
        right--;
    }
}
System.out.println(ok ? "YES" : "NO");

«А роза упала на лапу Азора» и «Нажал кабан на баклажан» дают YES, «Мама, мыла раму» даёт NO.

Character.isLetterOrDigit(c) отвечает, буква это или цифра. Пробел и запятая не буквы, и указатель просто шагает мимо них. Character.toLowerCase(c) опускает один символ, А и а становятся равны. За один проход цикла двигается один указатель. Оба сразу двигаются только после того, как пара букв сравнена и совпала.

Шаг 10 из 10

Проверка разворотом: StringBuilder.reverse

Второй способ узнать палиндром: развернуть строку и сравнить с исходной. Он короче, им удобно проверять своё решение двумя указателями.

public class Main {
    public static void main(String[] args) {
        check("шалаш");
        check("мопс");
        check("а");
        check("");
    }

    static void check(String s) {
        System.out.println("[" + s + "] указатели " + isPalindrome(s) + ", разворот " + byReverse(s));
    }

    static boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    static boolean byReverse(String s) {
        String reversed = new StringBuilder(s).reverse().toString();
        return s.equals(reversed);
    }
}
[шалаш] указатели true, разворот true
[мопс] указатели false, разворот false
[а] указатели true, разворот true
[] указатели true, разворот true

StringBuilder это изменяемая строка. new StringBuilder(s) делает её из обычной, .reverse() разворачивает, .toString() превращает обратно в String. Дальше обычный equals.

Разворот тратит память на вторую строку и всегда проходит её целиком. Два указателя останавливаются на первой несовпавшей паре и лишней памяти не берут. На лабе просили указатели, разворот это проверка.
