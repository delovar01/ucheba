Обучение с подкреплением и Q-learning

Шаг 1 из 10

Три способа учить машину

С учителем. Даём примеры и правильные ответы: «на фото кошка». Модель учится повторять. Так учат классификаторы.

Без учителя. Ответов нет. Модель сама ищет структуру в данных: группы похожих покупателей, похожие фильмы.

С подкреплением. Правильных ответов нет вообще. Есть только награда за действия. Как дрессировка собаки: сделал хорошо — получил лакомство, сделал плохо — ничего не получил. Машина сама ищет стратегию, которая приносит больше всего награды.

Обучение с подкреплением (RL): учимся по наградам, а не по примерам с ответами.

1) с учителем — есть правильные ответы; 2) без учителя — меток нет, ищем структуру; 3) с подкреплением — учимся по награде за действия.

Считать, что без учителя и с подкреплением одно и то же. Второе отличается тем, что агент сам действует и меняет среду, а награда приходит за каждый шаг.

С учителем: примеры + правильные ответы. Без учителя: ищем структуру. С подкреплением: только награда за действия.

Шаг 2 из 10

Агент и среда: главный цикл

Задачу описывают двумя ролями. Среда это всё, что вокруг: доска, лабиринт, игровой автомат. Агент это тот, кто учится: смотрит, где он, и делает ход.

смотрим на состояние s
  → выбираем действие a
    → среда возвращает награду r
      и новое состояние s′

Цикл повторяется шаг за шагом. Цель агента — набрать как можно больше награды за всё время, а не на одном шаге.

Три слова, которые надо знать уже здесь. Состояние s — где мы сейчас: клетка лабиринта, позиция на доске. Действие a — что агент может сделать: шаг влево, ход пешкой. Награда r — число от среды: +10 за цель, −1 за каждый лишний шаг.

Главный цикл RL: состояние → действие → награда и новое состояние. Состояние s, действие a, награда r.

s = A (где стояли), a = шаг в B (что сделали), r = −1 (шаг, но не цель). Новое состояние s′ = B.

Записать r = +10 за движение к цели. Награда идёт за результат шага: попал в G — +10, просто сходил — −1. Движение «в сторону цели» само по себе ничего не стоит.

Цикл: s → a → r и s′. Состояние s: где мы. Действие a: что делаем. Награда r: число от среды.

Шаг 3 из 10

Политика, эпизод и почему «потом» дешевле «сейчас»

Политика π это правило «в каком состоянии что делать». Это и есть то, чему учимся: хорошая политика в каждой клетке выбирает действие, которое ведёт к большей суммарной награде.

Эпизод это одна попытка от старта до конца: дошли до цели или проиграли. После конца всё начинается заново. Одну попытку и есть эпизод.

Агент максимизирует не одну награду, а сумму за эпизод. Здесь вылезает проблема: награда через десять шагов ценится меньше, чем та же награда сейчас. Дальние награды умножают на γ (читается «гамма»), число от 0 до 1:

\(G = r_1 + \gamma \cdot r_2 + \gamma^2 \cdot r_3 + \ldots\)

γ близко к 0 — думаем только о ближайшей награде, как животное, жрущее с ладони. γ близко к 1 — планируем надолго вперёд. На лабе γ = 0.9.

Политика π: правило «в состоянии s делай a». Эпизод: попытка от старта до конца. G — сумма наград эпизода с затуханием γ.

Сделай сам. Три шага подряд, награды −1, −1, +10, γ = 0.9. Посчитай G. Проверь каждую степень γ: γ = 0.9, γ² = 0.81.
Показать ответСкрыть ответ

\(G = -1 + 0{,}9 \cdot (-1) + 0{,}81 \cdot 10 = -1 - 0{,}9 + 8{,}1 = 6{,}2\).

Умножить +10 на 0.9, а не на 0.81. Третья награда умножается на γ²: две степени между первым шагом и третьим.

Политика π — то, что учим. Эпизод — попытка до конца. G = r₁ + γ·r₂ + γ²·r₃ + …

Шаг 4 из 10

Исследовать или использовать

Знаешь одно хорошее кафе. Пойти туда снова или рискнуть и попробовать новое — вдруг оно лучше? У агента эта дилемма на каждом шаге.

Исследование — случайное действие, чтобы узнать что-то новое о среде. Использование — лучшее действие по тому, что агент уже знает.

Стандартный компромисс — ε-жадная стратегия: с вероятностью ε (эпсилон, например 0.1) действуем случайно, иначе выбираем лучшее по текущим оценкам. ε = 0.1 значит: в среднем один шаг из десяти — проба, девять — игра по знаниям.

ε-жадная стратегия: с вероятностью ε — случайное действие, иначе — лучшее известное.

Сделай сам. ε = 0.2. Из 100 шагов сколько в среднем будет случайных? И что будет при ε = 0?
Показать ответСкрыть ответ

20 случайных из 100. При ε = 0 случайных шагов нет вообще — агент действует только жадно, исследования нет.

Думать, что ε = 0.2 значит «двадцать шагов подряд случайных, потом восемьдесят жадных». Вероятность размазывается по всем шагам: любой отдельный шаг случайный с шансом 0.2.

ε-жадно: с вероятностью ε пробуем случайное, иначе берём лучшее известное.

Шаг 5 из 10

Многорукий бандит: среднее по наградам

Первая задача с кода Зубарева. Три игровых автомата. У каждого скрытая вероятность выигрыша: 0.2, 0.5, 0.8. Агент её не знает и оценивает по опыту: оценка каждого автомата это просто среднее его наград.

Держать три суммы и пересчитывать среднее с нуля неудобно. Есть трюк: если было n наград и среднее Q, а пришла новая награда r, то новое среднее

\(Q \leftarrow Q + \dfrac{r - Q}{n}\)

Добавляем к старой оценке долю разницы. Первые награды сильно двигают среднее, поздние почти не замечаются: на десятой попытке правка (r − Q)/10 уже мала.

Код цикла на лабе, n это count[a] — сколько раз дёргали автомат a:

count[a]++;
estimate[a] += (reward - estimate[a]) / count[a];
Сделай сам. Автомат дали награды 1, 1, 0, 1 подряд. Посчитай оценку Q после каждой: старт с нуля, n растёт 1, 2, 3, 4.
Показать ответСкрыть ответ

Q₁ = 0 + (1 − 0)/1 = 1. Q₂ = 1 + (1 − 1)/2 = 1. Q₃ = 1 + (0 − 1)/3 = 0.67. Q₄ = 0.67 + (1 − 0.67)/4 = 0.75.

На третьем шаге получить 0.5 как «среднее 1, 1, 0». (1 + 1 + 0)/3 = 0.67, а не 0.5: три награды, не четыре.

Оценка автомата = среднее наград. Обновление: Q ← Q + (r − Q)/n, n — сколько раз дёргали.

Q[s][a] — таблица «цена действия a в состоянии s, если дальше играть лучше всего». Политика: в каждой клетке берём действие с большим Q.

Шаг 8 из 10

Формула Q-learning по частям

После каждого шага одна ячейка таблицы обновляется по формуле:

\(Q(s,a) \leftarrow Q(s,a) + \alpha \cdot [\; r + \gamma \cdot \max Q(s', \cdot) - Q(s,a) \;]\)

Три куска внутри скобок. \(r\) — награда, которую получили прямо сейчас. \(\gamma \cdot \max Q(s', \cdot)\) — сколько ещё можно взять из новой клетки s′, если дальше играть лучше всего; max берётся по обоим действиям из s′. \(\alpha\) — скорость обучения: насколько сдвигаем старую оценку к новой. На лабе α = 0.5.

Смысл целиком: «r + γ·max Q(s′)» это новая, более точная оценка хода, которую мы только что проверили опытом. Старую ячейку сдвигаем к ней на долю α. Оценка не прыгает в новое значение, а подтягивается к нему.

Разберём на пальцах из клетки 4 вправо, цель соседняя. Шаг даёт r = +10, s′ = цель. Из цели играть не надо, дальнейшую ценность считаем нулём. Новая оценка хода: 10 + 0.9·0 = 10. Ячейка Q(4, вправо) была 0, сдвигаем наполовину: 0 + 0.5·(10 − 0) = 5. Попадём туда ещё раз: 5 + 0.5·(10 − 5) = 7.5. Ещё раз: 8.75. Ячейка ползёт к 10.

Q[s][a] += ALPHA * (r + GAMMA * future - Q[s][a]);
// future = лучшее Q из новой клетки, а в цели — 0

Q-learning: новая цель хода = r + γ·(лучшее из новой клетки). Ячейку двигаем к ней на долю α.

Сделай сам. Из клетки 3 агент шагнул вправо в клетку 4, где лучшее Q = 10.00. Q(3, вправо) = 0, α = 0.5, γ = 0.9. Посчитай новую оценку хода и ячейку после первого обновления.
Показать ответСкрыть ответ

Награда за шаг: r = −1 (клетка 4 не цель). Новая оценка хода: −1 + 0.9·10.00 = 8. Обновление: 0 + 0.5·(8 − 0) = 4. Ячейка Q(3, вправо) стала 4.

Взять r = +10. Цель — клетка 5, а шаг был из 3 в 4. +10 даёт только приход в 5. За обычный шаг награда −1.

Формула: Q ← Q + α·(r + γ·max Q(s′) − Q). Новая цель − старое значение, сдвиг на долю α.

Шаг 10 из 10

Где это работает в жизни

Игры. AlphaGo обыграл чемпиона мира по го; агенты учатся играть в Atari, побивая людей, просто гоняя партии и получая награду за очки.

Роботы. Учатся ходить и брать предметы сначала в симуляторе: тысячи падений ни к чему не обязывают, а награда за удачный шаг остаётся.

Рекомендации. Что показать пользователю, чтобы он вернулся завтра: выбор ровно как у бандита, только «автоматов» миллионы.

Языковые модели. RLHF: модель учат по оценкам людей, какие ответы лучше. Это тот же принцип «награда вместо правильного ответа», только таблица Q заменена нейросетью.

RL: игры, роботы, рекомендации, RLHF. Домашка — MazeRL.java, Q-learning против BFS в лабиринте.

Q(4, вправо) = 10 (приход в цель, как раньше). Q(3, вправо) = −1 + 0.5·10 = 4. Q(2, вправо) = −1 + 0.5·4 = 1. Q(1, вправо) = −1 + 0.5·1 = −0.5. Q(0, вправо) = −1 + 0.5·(−0.5) = −1.25.

Числа стали меньше и растут медленнее к цели: с γ = 0.5 агент почти не заглядывает вперёд. Политика та же — вправо всё равно лучше, чем влево, — но ценности прижались к нулю.

Ожидать, что агент «не дойдёт» до цели при γ = 0.5. Политика не ломается, меняются только числа: сравнение «вправо против влево» остаётся в пользу «вправо».

RL в жизни: игры, роботы, рекомендации, RLHF. γ маленькое — планируем на короткую дистанцию.
