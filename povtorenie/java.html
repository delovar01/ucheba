Java: проверь себя

Одиннадцать уроков, 45 вопросов. Числа в вопросах новые, не из уроков. Ответь вслух или в голове, потом открывай ответ. Все ответы с выводом программы проверены запуском.

Не помнишь, вернись в урок: 1–5 типы, формулы и if, 6–10 циклы и методы, 11–14 массивы, 15–17 среда разработки, 18–21 строки и палиндром, 22–25 классы и объекты, 26–29 инкапсуляция, 30–33 наследование, 34–37 лямбды и Stream, 38–41 sealed и record, 42–45 исключения и null.

Вопросы

1. Что напечатает System.out.println(9 / 4 + " " + 9 % 4 + " " + 9 / 4.0);?

2 1 2.25. Целое деление, остаток, деление с дробью: 4.0 дробное, поэтому и ответ дробный.

2. Почини строки float t = 36.6; и char c = "x";.

float t = 36.6f;: число с точкой без f считается double. char c = 'x';: символ пишется в одинарных кавычках, двойные дают строку.

3. Функция y = √(x − 1) / (x + 2). Какое условие «не определена» достаточно написать?

x < 1. Знаменатель ноль при x = −2, но −2 меньше 1 и уже попало под запрет корня. Писать x < 1 || x == -2 не ошибка, просто вторая часть лишняя.

4. Цепочка: сначала if (s >= 50) «удовлетворительно», потом else if (s >= 85) «отлично». Что получит s = 90?

«удовлетворительно». Цепочка берёт первую верную ветку, 90 ≥ 50 верно, до проверки на 85 дело не дойдёт. Условия ставят от самого строгого к мягкому.

5. Почему hasNextDouble() проверяют до nextDouble(), а не после?

Если ввели буквы, nextDouble() сам падает с InputMismatchException, и до проверки программа не доходит. hasNextDouble() только заглядывает во ввод и ничего не забирает.

6. Сколько раз надо целочисленно разделить 1000 на 3, чтобы получился 0? Какой цикл возьмёшь?

7 раз: 333, 111, 37, 12, 4, 1, 0. Число шагов заранее неизвестно, значит while (n > 0).

7. k = 10. Чему равно k после while (k < 5) k++;, и чему после do { k++; } while (k < 5);, если начать снова с 10?

10 и 11. while проверяет условие до тела и не выполнит его ни разу. do-while выполняет тело хотя бы один раз.

8. Сумма нечётных чисел от 1 до 9 одним for. Как будет выглядеть заголовок цикла и что выйдет?

for (int i = 1; i <= 9; i += 2), накопитель с 0, ответ 25: 1 + 3 + 5 + 7 + 9.

9. static int twice(int x) { x = x * 2; return x; }. В main: int a = 4; twice(a); System.out.println(a);. Что напечатает?

4. Метод удвоил свою копию и вернул 8, но ответ никто не забрал. Нужно a = twice(a);.

10. Почему не собирается static double half(double x) { double h = x / 2; }?

Метод обещает вернуть double, а return нет. Компилятор скажет missing return statement. Нужно return x / 2;.

11. int[] a = {6, 1, 8};. Что даст a[a.length - 1], а что a[3]?

8, последний элемент. a[3] уронит программу с ArrayIndexOutOfBoundsException: индексы только 0, 1, 2.

12. Массив {-3, -7}, максимум начали с max = 0. Что выйдет и как правильно?

Выйдет 0, хотя нуля в массиве нет. Правильно начать с max = a[0] и цикл с i = 1, тогда −3.

13. По правилу Павлова сколько участков убывания в {7, 7, 3, 5, 2, 2, 9}?

Два: 7, 7, 3 и 5, 2, 2. Равные соседи участок не рвут, рвёт только рост: 3 и 5, 2 и 9.

14. Чем отличаются System.out.println(a) и System.out.println(Arrays.toString(a)) для массива?

Первое печатает служебную метку, тип и номер объекта, вроде [I@…, второе содержимое [6, 1, 8]. Для Arrays нужен import java.util.Arrays;.

Среда, строки, классы, инкапсуляция

15. javac Task2.java прошёл без ошибок. Какой командой запустить программу?

java Task2, имя класса без расширения. java Task2.class ответит Could not find or load main class.

16. Компилятор пишет Main.java:7: error: cannot find symbol, ниже symbol: variable cnt. Что и где искать?

Строку 7 и имя cnt: оно не объявлено, объявлено в другом блоке или написано с опечаткой, например переменная называется count. Регистр тоже считается.

17. Программа напечатала первую строку и остановилась: Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException, ниже at Main.main(Main.java:9). Ошибка компиляции или исключение?

Исключение: программа собралась и упала при запуске. Причина в строке 9, индекс вышел за границу массива. Компиляция бы не дала даже начать.

18. Чему равны "Урал".length() и "Урал".charAt(3)? Что будет на charAt(4)?

4 и 'л', номера с 0. charAt(4) падает: StringIndexOutOfBoundsException: Index 4 out of bounds for length 4.

19. int n = sc.nextInt(); String s = sc.nextLine();. Ввели 7, Enter. Что в s и как починить?

Пустая строка "": nextLine дочитал остаток строки после 7. После nextInt нужен холостой sc.nextLine();, потом настоящий.

20. String a = sc.next();, ввели нет. Что дадут a == "нет" и a.equals("нет")?

false и true. == сравнивает ссылки, а строка с клавиатуры новый объект. Буквы сравнивает equals.

21. Палиндром двумя указателями. Сколько сравнений на «ротор» и на «ротик», что ответит программа?

«ротор»: р и р, о и о, середина т, 2 сравнения, YES. «ротик»: р и к разные, 1 сравнение, NO.

22. class Cat { String name; int lives; }. Что напечатает Cat c = new Cat(); System.out.println(c.name + " " + c.lives);?

null 0. Поля без значения получают значения по умолчанию: объекты null, числа 0.

23. Конструктор Cat(String name) { name = name; }. Что окажется в поле после new Cat("Мурка")?

null. Параметр перекрыл поле, и name = name присвоил параметр самому себе. Нужно this.name = name;.

24. Cat a = new Cat("Мурка"); Cat b = a; b.name = "Барсик";. Чему равны a.name и a == b?

Барсик и true. b = a скопировал ссылку, объект один.

25. Компьютер имеет список деталей по 300, 150 и 150. Что такое композиция и что вернёт totalPrice(), который суммирует цены частей?

Композиция: поле объекта само является объектом или списком объектов, компьютер «имеет» детали. Ответ 600.0.

26. Поле private double balance. Что скажет компилятор на card.balance = 5; в main?

balance has private access in Account. Закрытое поле видно только внутри класса, менять его можно только через методы класса.

27. Сеттер setHeight(double v) { if (v > 0) height = v; }. Вызвали setHeight(1.2), потом setHeight(0). Что вернёт getHeight()?

1.2. Ноль не прошёл проверку, поле не тронуто. Это тихий отказ, громкий делают через throw new IllegalArgumentException(…).

28. Поле private final String name. Можно ли дописать к нему сеттер?

Нет: cannot assign a value to final variable name. final поле присваивают один раз, в конструкторе или при объявлении.

29. Две точки new Point(1, 2) без своего equals. Что даст a.equals(b), и что нужно, чтобы стало true?

false: стандартный equals сравнивает ссылки. Нужен свой @Override public boolean equals(Object o), который сравнивает поля, и вместе с ним hashCode.

30. B extends A, в B переопределён hi(): печатает «B» и вызывает super.hi(), у A он печатает «A». Что даст A x = new B(); x.hi();?

«B», потом «A». Переменная типа A, но метод выбирается по объекту, а он B. super.hi() зовёт версию родителя.

31. C extends B, B extends A, конструкторы печатают 3, 2 и 1. Что напечатает new C()?

1 2 3 по строкам. Конструкторы работают от родителя к наследнику: каждый сначала неявно вызывает super().

32. abstract class Animal с методом abstract String sound();. Что скажет компилятор на new Animal(), и что обязан сделать наследник?

Animal is abstract; cannot be instantiated. Обычный наследник обязан написать sound(), иначе «is not abstract and does not override abstract method sound()».

33. Соберётся ли class Duck extends Bird implements Swimmer, Flyer? А class Duck extends Bird, Fish?

Первое да: родитель один, интерфейсов сколько угодно. Второе нет, '{' expected: два родителя в Java нельзя.

34. f = x -> x * 3, g = x -> x - 2, обе Function<Integer, Integer>. Что вернут f.andThen(g).apply(4) и g.andThen(f).apply(4)?

10 и 6. В первом 4·3 = 12, минус 2. Во втором 4 − 2 = 2, умножить на 3. andThen выполняет слева направо.

35. Что напечатает List.of(7, 2, 9, 4, 6).stream().filter(x -> x > 4).map(x -> x * 10).toList()?

[70, 90, 60]. Остались 7, 9, 6 в том же порядке, потом каждое умножено на 10.

36. Для List.of(2, 3, 4): что дадут reduce(1, (a, b) -> a * b) и filter(x -> x % 2 == 0).count()?

24 и 2. Произведение начинают с 1, чётных два: 2 и 4.

37. Какой готовый интерфейс подходит для () -> "привет" и для s -> s.isEmpty()? Можно ли внутри лямбды написать count++ для локальной count?

Supplier<String> и Predicate<String>. Нельзя: локальные переменные лямбда только читает, ошибка «must be final or effectively final».

38. record Point(int x, int y) {}. Point p = new Point(3, -1);. Что напечатают System.out.println(p) и System.out.println(p.x() + p.y())? Есть ли у неё getX()?

Point[x=3, y=-1] и 2. getX() нет, методы чтения называются как поля: x().

39. record Age(int value) { Age { if (value < 0) throw new IllegalArgumentException("минус"); } }. Как называется такой конструктор и что будет от new Age(-3)?

Компактный конструктор, параметры не перечисляют, поля Java присваивает сама. new Age(-3) бросит IllegalArgumentException: минус, объект не создастся.

40. sealed interface Animal permits Cat, Dog, в switch ветки для Cat и Dog без default. В permits дописали Fox. Что будет?

Не соберётся: the switch expression does not cover all possible input values. Компилятор знает всех наследников и требует ветку для лисы. Ради этого default и не пишут.

41. case Sq(int a) -> 4 * a и case Rect(int a, int b) -> 2 * (a + b). Что вернёт метод для new Sq(5) и new Rect(2, 7)?

20 и 18. Шаблон записи проверяет тип и раскладывает запись на поля по порядку заголовка.

42. В try печать «1», запись в a[3] массива длины 2, печать «2». catch (ArrayIndexOutOfBoundsException e) печатает «3», finally «4», после всего «5». Что выйдет?

1 3 4 5 по строкам. «2» пропущено, исключение поймано, finally отработал, программа пошла дальше.

43. Какие из них проверяемые: IOException, IllegalArgumentException, NullPointerException, FileNotFoundException?

IOException и его наследник FileNotFoundException. Два других наследники RuntimeException, компилятор их не проверяет.

44. Optional.ofNullable(nothing), где nothing равен null, дальше .map(String::toUpperCase).orElse("пусто"). А Optional.of("Java").map(String::length).orElse(0)?

«пусто» и 4. На пустой коробке map ничего не делает, и срабатывает запас.

45. Ресурс в try (R r = new R()) печатает «открыл» и «закрыл». Внутри throw new RuntimeException("бах"), catch печатает текст. Порядок вывода?

«открыл», «закрыл», «бах». Ресурс закрывается до того, как сработает catch.
