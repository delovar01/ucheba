Матан: проверь себя

Сначала ответь в тетради, потом открой ответ. 10 минут.

Урок к этим вопросам — логарифмы, пределы, производные, суммы.

Вопросы

1. Что значит log₂ n простыми словами?

Сколько раз можно поделить n пополам, пока не останется 1. Поэтому бинарный поиск по n элементам делает около log₂ n шагов.

2. Почему в O(log n) не пишут основание?

По формуле смены основания логарифмы отличаются только множителем-числом: log₄ n = log₂ n / 2. А множители в O не учитывают.

3. Сколько примерно log₂ миллиарда?

Около 30: 2¹⁰ ≈ 10³, у миллиарда три тройки нулей, 3 · 10 = 30.

4. Как через предел понять, что растёт быстрее?

Смотрим lim f/g при n → ∞. 0 — быстрее g, ∞ — быстрее f, конечное число больше нуля — одинаково.

5. Когда работает правило Лопиталя и что в нём дифференцируют?

Когда числитель и знаменатель оба уходят в ∞ или оба в 0. Производную берут отдельно от числителя и отдельно от знаменателя, не по формуле производной частного.

6. Производная 4x³ − 2x + 9?

12x² − 2. Степень падает на один, константа 9 даёт 0.

7. Что говорит знак производной?

Больше нуля — функция растёт, меньше — падает, ноль — точка, где может быть минимум или максимум. Градиентный спуск ищет точку, где производная функции ошибки равна нулю.

8. Цикл «каждый с каждым» — сколько шагов?

(n−1) + … + 1 + 0 = n(n−1)/2, это Θ(n²).

9. Почему добавление в конец списка Python в среднем O(1)?

При переполнении массив удваивается. Все копирования вместе — геометрическая сумма 1 + 2 + 4 + … + n < 2n, то есть в среднем меньше двух копирований на одно добавление.

10. Внутренний цикл идёт с шагом i. Почему это n log n, а не n²?

Внутренний цикл делает примерно n/i шагов. Всего n(1 + 1/2 + … + 1/n) = n · H_n ≈ n ln n.
