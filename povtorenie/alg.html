Вопросы

1. Упрости O(4n³ + n² log n + 1000) и O(log₅ n + 7).

O(n³): n² log n ниже n³ по лестнице, ведь log n растёт медленнее n. O(log n): основание логарифма не пишут, число 7 младше логарифма.

2. Начинаем с i = 1. Пока i ≤ n, внутренний цикл делает i шагов, потом i удваивается. Сколько всего шагов внутреннего цикла при n = 64 и какой порядок?

i проходит 1, 2, 4, …, 64. Сумма 1 + 2 + … + 64 = 127, меньше 2n. Порядок Θ(n), а не n log n: внутренний цикл идёт до i, а не до n.

3. Реши мастер-теоремой T(n) = 8T(n/2) + n².

Листьев n^(log₂ 8) = n³. f = n² меньше по степени, случай 1. Ответ Θ(n³).

4. Не меньше скольких сравнений нужно в худшем случае, чтобы отсортировать 7 элементов? 7! = 5040.

2¹² = 4096 < 5040 ≤ 8192 = 2¹³, значит не меньше 13. Дерево решений должно иметь 5040 листьев, а у дерева высоты 12 их не больше 4096.

5. Вставь 1 в min-кучу [2, 4, 3, 6, 5]. Какой массив получится?

В конец, индекс 5. Родитель 2, там 3, меняем: [2, 4, 1, 6, 5, 3]. Родитель 0, там 2, меняем: [1, 4, 2, 6, 5, 3].

6. Динамический массив удваивается, ёмкость сначала 1. Сколько всего операций, записей и копирований, на 32 добавления?

Записей 32. Копирования при ёмкости 1, 2, 4, 8, 16: 1 + 2 + 4 + 8 + 16 = 31. Всего 63, меньше 2 · 32, по O(1) на добавление.

7. Чему равен digitSum(4096) и сколько вызовов будет в стеке одновременно? База n < 10, шаг n % 10 + digitSum(n / 10).

6 + 9 + 0 + 4 = 19. Вызовы для 4096, 409, 40 и 4, все ждут друг друга, глубина 4.

8. Сколько подмножеств у {2, 4, 6}? Какие из них дают в сумме 6? Зачем в переборе строка отката remove?

2³ = 8 подмножеств. Сумма 6 у {6} и {2, 4}. Откат убирает элемент после ветки «беру», чтобы следующая ветка начала с того же набора. Без него элементы копятся и печатается лишнее.

9. Граф: рёбра 1–2, 2–3, 3–4, 1–4, 4–5. BFS из 1, соседи по возрастанию. Расстояния до всех вершин?

1:0, 2:1, 4:1, 3:2, 5:2. Из очереди выходят 1, 2, 4, 3, 5. До 3 два ребра любым путём, через 2 или через 4.

10. Вершины 1–7, рёбра 1–2, 3–4, 4–5, 6–7. Сколько компонент связности и как их посчитать кодом?

Три: {1, 2}, {3, 4, 5}, {6, 7}. Перебираем вершины по порядку и от каждой непосещённой запускаем DFS с общим массивом меток. Запусков будет 3.

11. Ориентированный граф: A→B 6, A→C 2, C→B 3, B→D 1, C→D 7. Расстояния Дейкстрой из A?

Фиксируем A: B = 6, C = 2. Фиксируем C: B = min(6, 5) = 5, D = 9. Фиксируем B: D = min(9, 6) = 6. Фиксируем D. Итог A 0, C 2, B 5, D 6.

12. Почему Дейкстра не работает с отрицательными весами и что брать вместо неё?

Дейкстра фиксирует ближайшую вершину навсегда, считая, что обходной путь только длиннее. С отрицательным ребром обход через дальнюю вершину может оказаться короче, а исправить зафиксированное уже нельзя. Вместо неё Форд–Беллман, O(n · m).

13. Отсортируй подсчётом [1, 3, 1, 0, 3], k = 3. Запиши счётчики, префиксные суммы и итог.

Счётчики [1, 2, 0, 2], префиксы [1, 3, 3, 5]. Справа налево: 3 в B[4], 0 в B[0], 1 в B[2], 3 в B[3], 1 в B[1]. Итог [0, 1, 1, 3, 3].

14. Почему в устойчивом подсчёте по входу идут справа налево? Что сломается слева направо?

После префиксов C[x] указывает на конец места для x. С конца входа последний из равных встаёт на последнее место, предыдущий левее, и порядок равных сохраняется. Слева направо первый из равных займёт последнее место, порядок равных развернётся, и поразрядная сортировка на таком проходе даст неверный ответ.

15. Отсортируй поразрядно с младшей цифры [324, 142, 321, 244]. Что после каждого прохода?

По единицам: [321, 142, 324, 244]. По десяткам: [321, 324, 142, 244]. По сотням: [142, 244, 321, 324]. У 321 и 324 одна сотня, их порядок сохранил устойчивый проход.

16. Миллион целых, каждое меньше 10¹². Подсчёт, поразрядная или карманная? Сколько проходов при основании 10⁶ и примерно шагов?

Подсчёту нужен массив на 10¹² ячеек, столько памяти нет. Карманная рассчитана на равномерные дроби. Поразрядная в основании 10⁶: у числа меньше 10¹² два разряда, значит 2 прохода по 10⁶ + 10⁶, всего около 4 · 10⁶ шагов.

17. Рюкзак на 3 кг: А (вес 1, ценность 6), Б (2, 10), В (3, 12). Таблица ДП, лучшая ценность и что взяли?

Строка А: 0, 6, 6, 6. Б: 0, 6, 10, 16, при c = 3 берём Б и смотрим выше при c = 1: 6 + 10. В: 0, 6, 10, 16, взять В даёт только 12. Ответ 16. Обратно: В не изменил ячейку, не взят. Б изменил, взят, c = 1. А при c = 1 изменил, взят. Набор А + Б.

18. Длина наибольшей общей подпоследовательности строк ПАРК и ПРАК? Какое правило при совпадении символов?

3, например ПАК или ПРК. Все четыре не выйдет: строки разные, а длина одна. При совпадении берём ячейку по диагонали и прибавляем 1, dp[i−1][j−1] + 1. При несовпадении больший из соседей сверху и слева.

19. Рёбра A–B 4, A–C 1, B–C 2, B–D 5, C–D 8, D–E 3, C–E 7. Минимальный остов Краскалом: какие рёбра и какой вес?

По возрастанию: A–C 1 берём, B–C 2 берём, D–E 3 берём, A–B 4 цикл, B–D 5 берём, дальше рёбер уже n − 1 = 4. Остов A–C, B–C, D–E, B–D, вес 1 + 2 + 3 + 5 = 11.

20. DSU на вершинах 0–3 с рангом и сжатием путей. union(0, 1), union(2, 3), union(1, 3), потом find(3). Какие parent и rank в конце?

После первых двух parent = [0, 0, 2, 2], ранги 0 и 2 по 1. union(1, 3): корни 0 и 2, ранги равны, 2 под 0, ранг 0 стал 2: parent = [0, 0, 0, 2], rank = [2, 0, 1, 0]. find(3) идёт 3 → 2 → 0 и перевешивает 3 на 0: parent = [0, 0, 0, 0].

21. Чем Краскал отличается от Прима и какая у каждого сложность?

Краскал сортирует все рёбра и берёт лёгкие, если концы в разных кусках, проверка через DSU, O(m log m). Прим растит одно дерево из вершины и берёт самое лёгкое ребро наружу, через кучу, O(m log n). Оба дают минимальный остов одного веса. На слайде подписи перепутаны, запоминай так.

22. Стрелки 0→1, 0→2, 1→3, 2→3, 2→4, 3→4. Топосортировка DFS, соседи по возрастанию: порядок выхода и ответ?

DFS(0) → 1 → 3 → 4. Выходы: 4, 3, 1. Потом из 0 в 2, у неё соседи 3 и 4 уже посещены, выход 2, выход 0. Порядок выхода 4, 3, 1, 2, 0, развернули: 0, 2, 1, 3, 4.

23. Форд–Беллман из S, рёбра по порядку: S→A 2, S→B 6, A→B 3, B→C −4, A→C 5. Расстояния? Сколько проходов делает алгоритм?

Проход 1: A = 2, B = 6, через A B = 5, C = 5 − 4 = 1, A→C даёт 7, не лучше. Итог A 2, B 5, C 1. Проходы 2 и 3 ничего не меняют. Алгоритм всё равно делает n − 1 = 3 прохода и ещё один проверочный на отрицательный цикл.

24. Когда Дейкстра, когда Форд–Беллман, когда Флойд? Какая сложность у каждого?

Один старт и веса ≥ 0: Дейкстра, O(n²) на массиве или O((n + m) log n) с кучей. Один старт и есть отрицательные веса или нужно найти отрицательный цикл: Форд–Беллман, O(n · m). Все пары при небольшом n: Флойд, O(n³), циклы k, i, j, k внешний.

25. Слей [3, 8, 9] и [1, 8, 10]. Сколько сравнений? Какую восьмёрку надо взять первой, чтобы сортировка была устойчивой?

3 и 1 берём 1, 3 и 8 берём 3, 8 и 8 берём левую, 9 и 8 берём 8, 9 и 10 берём 9, дописываем 10. Ответ [1, 3, 8, 8, 9, 10], пять сравнений. При равенстве берём из левой половины, это <= в слиянии.

26. Разбиение Ломуто массива [5, 1, 6, 2, 4], опорный последний. Что получится и на каком месте опорный?

Опорный 4. 5 пропуск, 1 меньше, обмен с a[0]: [1, 5, 6, 2, 4], i = 1. 6 пропуск, 2 меньше, обмен с a[1]: [1, 2, 6, 5, 4], i = 2. Опорный в a[2]: [1, 2, 4, 5, 6], место 2.

27. Слияние и быстрая сортировка: время в худшем и среднем, память, устойчивость. Как у быстрой избежать худшего?

Слияние: T(n) = 2T(n/2) + n = Θ(n log n) всегда, память Θ(n), устойчива при <=. Быстрая: в среднем Θ(n log n), худший Θ(n²), когда опорный каждый раз крайний, например последний на отсортированном массиве. Память на стек O(log n) в среднем, неустойчива. Спасает случайный опорный или медиана трёх.
